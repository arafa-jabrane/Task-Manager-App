# Smart-Expense-Tracker-
A clean web app to manage personal finances.
Core features:

Add / edit / delete transactions
Categories (food, rent, etc.)
Monthly summary (income vs expenses)
Local storage (no backend needed)

Tech skills you’ll show:

DOM manipulation (JS)
Data persistence with localStorage
Dynamic UI updates
Basic data visualization (charts with CSS or a small library)

Bonus ideas:

Dark mode toggle
Export data to CSV
Budget alerts
